# 桌游规则复习卡库

一个纯前端本地应用，把桌游收藏整理成规则复习卡库，聚会前逐张确认遗忘点，确认完毕再记开局。

- 录入游戏名称、支持人数、复杂度和上次游玩日期，可按人数与复杂度筛选、搜索和排序
- 每张规则卡（容易忘的规则 / 常见争议 / 开局准备 / 计分提醒）都可以勾选「本次已确认」
- 准备开局时填写本次人数，人数不在支持区间内无法开局
- 人数适配且全部规则卡确认后，才能「记为已玩」
- 开局成功后自动清空本次勾选、更新上次游玩日期，并保留一条开局记录
- 列表、统计、勾选与开局记录全部存入 localStorage，刷新后自动恢复

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
