# 桌游规则复习卡库

一个纯前端本地应用，用于录入桌游、复习规则卡，并在聚会开局时逐卡确认规则。所有数据保存在浏览器 `localStorage`，刷新后恢复。

## 功能

- **录入桌游**：游戏名称、支持人数（最少/最多）、复杂度（轻/中/重）、上次游玩日期。
- **规则卡**：每个游戏可添加「容易忘的规则 / 常见争议 / 开局准备 / 计分提醒」四类卡片；卡片可标记为已掌握、删除或补充。
- **筛选与排序**：按关键词、人数（含 7 人及以上）、复杂度筛选，按最久未玩、名称或复杂度排序。
- **本次确认**：开局会话中，每张未掌握的规则卡可勾选「本次已确认」，实时显示进度。
- **开局流程**：
  1. 准备开局时选择游戏与本次人数，人数不在支持范围内无法开始；
  2. 同时只允许一个开局会话，进行中其他游戏不能开局；
  3. 所有未掌握规则卡都勾选确认后，才能点击「全部确认并记为已玩」；
  4. 成功后清空本次勾选、把上次游玩日期更新为今天，并保留一条开局记录（游戏、人数、日期）。
- **统计**：顶部汇总收藏游戏数、未掌握规则数、开局记录数与最久未玩游戏，随本地数据实时同步。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
